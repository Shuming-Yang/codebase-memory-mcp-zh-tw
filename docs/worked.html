教學解說

實作案例展示 CBM 的真實產出——不是示意圖，而是用 graphify 工具掃描 CBM 自己的源碼產生的互動知識圖譜。這是一個「meta 示範」：用一個知識圖譜工具分析另一個知識圖譜工具。

343 個社群自然地對應 CBM 的模組結構（Cypher engine、MCP server、Daemon IPC…），側面驗證了 CBM 的架構乾淨度。

Worked Example

重現 CBM 源碼知識圖譜的步驟：

# 1. 安裝 graphify
uv tool install graphifyy

# 2. 準備語料
git clone https://github.com/DeusData/codebase-memory-mcp.git cbm
mkdir corpus && cp -R cbm/src corpus/ && cp -R cbm/tests corpus/

# 3. 跑 code-only 分析
graphify corpus --code-only

# 4. 產出在 graphify-out/
ls graphify-out/
# → graph.html（互動圖）、graph.json（全量資料）、GRAPH_REPORT.md（審計報告）

# 5. 中文化（選擇性）
cp graphify-out/graph.html graphify-out/graph-zh.html
# 替換 UI 字串

常見錯誤 / 診斷

症狀原因解法
graphify 安裝失敗套件名是 graphifyy（雙 y）用 uv tool install graphifyy
互動圖只顯示社群聚合節點數超過 5,000 上限縮小語料範圍或用社群檢視
審計報告缺少某些模組語料排除了 vendored grammars這是預期行為（只分析第一方程式碼）
