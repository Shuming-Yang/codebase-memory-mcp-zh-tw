教學解說

文件教學是整個教學站的入口——把上游 README 與 docs 的官方文件，依「值得教學」原則做中文解說。每個主題一頁，中文為主文，英文原文保留。

建議的閱讀順序是：運作原理 → 架構總覽 → 圖資料模型 → MCP 工具 → Cypher 查詢。這五頁建立基礎理解後，再依需求深入其他主題。

Worked Example

建議的學習路線：

  1. 運作原理：理解 CBM 為什麼不內建 LLM、兩層解析是什麼
  2. 架構總覽：看懂 15 個模組的職責與資料流
  3. 圖資料模型：認識 13 種節點和 23 種邊
  4. MCP 工具：學會 15 個工具的四類分法
  5. Cypher 查詢：掌握唯讀子集的語法
  6. 程式碼對照：深入看 C 源碼的實現
