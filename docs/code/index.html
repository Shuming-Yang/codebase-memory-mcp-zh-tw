程式碼對照

純 C 源碼逐函數講解——每個函數一個收縮塊，中文解說配英文原始碼

codebase-memory-mcp 是純 C（約 13 萬行），不像 graphify（Python）那樣好讀。這裡挑「最高教學價值」的模組逐函數講解。所有行數為對齊版 main @ 2c50c77 實測。

main.c單一二進位入口：MCP stdio server + CLI + install/update/config 的分派。 mcp/mcp.c15 個 MCP 工具註冊、JSON-RPC 2.0、session detection、auto-index。 store/store.cSQLite 節點/邊/遍歷/搜尋/Louvain 社群偵測。 cypher/cypher.copenCypher 唯讀子集的 lexer→parser→planner→executor。 cli/cli.cinstall/uninstall/update/config、43 個 client surface、hook 安裝。 pipeline/多 pass 索引的調度（pipeline.c + registry.c）。 pipeline/pass_*.c各 pass 職責：parallel/pkgmap/lsp_cross/semantic_edges/cross_repo/infrascan/route_nodes… daemon/會話協調 daemon、IPC、admission barrier、lifecycle。 discover/檔案發現：.gitignore → .cbmignore → symlink 處理。 semantic/語意搜尋：nomic-embed-code（768d int8）、11-signal scoring、MinHash/ROTSQ。 ui/3D 圖形 UI、embedded assets、HTTP server（localhost:9749）。 tests/6,768 tests / 120 suites 測試策略、fixtures、grammar_cases。
全站已建置：12 個程式碼對照頁全部完成（對齊上游 main @ 2c50c77）。建議閱讀順序：main → mcp → store → cypher → cli。
