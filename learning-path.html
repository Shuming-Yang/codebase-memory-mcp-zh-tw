學習路線

從「裝好」到「讀 C 源碼」的五層路線
L0裝好它10 分鐘內讓 CBM 跑起來
安裝macOS/Linux 一行安裝、Windows PowerShell、--ui 圖形界面變體。 15 個工具一覽知道 index/query/read/ops 四類工具各做什麼。
L1跑起來對一個專案 index 並開始問結構問題
index_repository對你的專案建立知識圖譜，auto-sync 讓它保持新鮮。 search_graph用 name_pattern / label / degree 做結構搜尋。 trace_path追蹤誰呼叫誰，深度 1–5。 實作案例看真實 repo 的索引結果與查詢輸出。
L2讀懂圖理解知識圖譜的結構與查詢語言
圖資料模型13 種節點 label、23 種邊型、qualified name。 Cypher 子集openCypher 唯讀子集：MATCH/WHERE/EXISTS、死碼查詢。 detect_changes把 git diff 映射到受影響符號 + blast radius。 graph.db.zst團隊共享的壓縮圖快照，隊友 clone 免重 index。
L3讀原理理解索引管線與效能/安全設計
運作原理無內建 LLM 的哲學、兩層解析（tree-sitter + Hybrid LSP）、RAM-first pipeline。 架構總覽15 個 src/ 模組職責、索引 pass 順序。 效能基準Linux kernel 3min、Cypher <1ms、token 省 99.2%。 安全模型SLSA3/cosign/VirusTotal/CodeQL、零依賴、無 telemetry。 Daemon一帳號一協調 daemon、admission barrier、CLI 分離。 設定config 指令、CBM_* 環境變數、.cbmignore、extra_extensions。
L4讀 C 源碼直接進 13 萬行純 C 的逐函數講解
mcp/mcp.c15 工具註冊、JSON-RPC 2.0、session detection。 store/store.cSQLite 圖儲存、遍歷、Louvain。 cypher/cypher.cCypher lexer→parser→planner→executor。 main.c單一二進位入口的分派。 cli/cli.cinstall/update/config、43 個 client surface。 全部程式碼對照13 頁逐函數講解。
看完這條路線你應該能：獨立安裝並使用 CBM 讀懂任何專案、寫出 Cypher 死碼查詢、解釋 Hybrid LSP 為何比純 tree-sitter 強、並能追著 mcp.c 的註冊流程看 source。
