codebase-memory-mcp（CBM） 是一個用純 C 寫的 MCP server： 用 tree-sitter 把整個專案在毫秒級解析成持久化的知識圖譜（函式、類別、呼叫鏈、 HTTP 路由、跨服務連結），並提供 15 個 MCP 工具——用「問結構問題」 取代「一個檔案一個檔案地 grep」，查詢比檔案式探索省 99.2% token。
