教學方法

  1. 中英對照中文口語解說為主文，英文原文與程式碼保留上游原貌（文件頁用可展開的原文、程式碼頁用註解版原始碼）。
  2. 程式碼逐函數所有講到的 C 函數一個 <details> 收縮塊（signature + 中文用途 + 關鍵邏輯），核心函數附逐行中文註解；短函數用段落式說明。
  3. 策展而非鏡像13 萬行 C 的 repo 不逐檔翻譯，挑「值得教學」的模組（mcp/store/cypher/cli/pipeline/daemon…）深入講解。
  4. 實機示範收錄真實工具產出（graphify 互動圖、CBM CLI 查詢輸出），訪客可直接操作，並提供可重現步驟。

關於 codebase-memory-mcp

codebase-memory-mcp 是一個用純 C 寫的高效能 code intelligence MCP server：用 tree-sitter（158 語系）+ Hybrid LSP 型別解析，把 repo 在毫秒級索引成持久化知識圖譜，提供 15 個 MCP 工具讓 agent 用「問結構問題」取代逐檔 grep。單一靜態二進位、零依賴、100% 本機處理。

  • 官方 repo：DeusData/codebase-memory-mcp
  • 研究論文：arXiv:2603.27277
  • 官方網站：deusdata.github.io/codebase-memory-mcp
  • 授權：MIT（Copyright (c) 2025 DeusData）
